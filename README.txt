윈도우용 당첨자 PPT 생성기
============================

필수 파일명
-----------
같은 작업 폴더 안에 아래 4개 파일을 넣습니다.

1. 전체.csv
2. 블락.csv
3. 상품.csv
4. 당첨자.pptx

CSV 컬럼명
----------
전체.csv / 블락.csv는 아래 컬럼 중 하나를 포함하면 됩니다.

이름 컬럼 허용 예: 이름, 성명, 신청자, 참가자, 회원명, name
전화 컬럼 허용 예: 휴대전화, 휴대폰, 핸드폰, 전화번호, 연락처, phone, mobile

상품.csv 예시
-------------
상품명,인원수,중복허용
골드바 1돈,1,아니오
플레이스테이션5 슬림,10,아니오
신세계 상품권,25,아니오

중복허용 컬럼은 선택입니다.
- 예/네/허용/O/1/true/yes → 다른 상품 중복 당첨 허용
- 아니오/아니요/불가/X/0/false/no → 다른 상품 중복 당첨 불가

상품.csv에 중복허용 컬럼이 있으면 프로그램 화면의 체크박스보다 상품.csv 값이 우선됩니다.
한 상품 안에서는 항상 같은 사람이 중복 당첨되지 않습니다.

출력
----
- PPTX: 작업폴더\당첨자\당첨자_N.pptx
- CSV: 작업폴더\당첨자_N.csv

CSV 출력 컬럼은 다음과 같습니다.
번호,이름,전화번호

번호는 전체.csv 안에서 해당 사람이 몇 번째 줄에 있었는지입니다.
헤더가 1행이면 첫 번째 데이터는 2번으로 기록됩니다.

PPT 입력 방식
-------------
당첨자.pptx의 표 안에서 상품명 셀을 찾고, 바로 오른쪽 셀에 당첨자를 입력합니다.
출력 형식은 예: 홍길동(1234) 김철수(5678) 입니다.

EXE 만들기
----------
1. Python 설치
2. 이 폴더에서 build_exe.bat 실행
3. dist\WinnerGenerator.exe 생성
